# Стенд STT: регистрации и запуск (тикет nikitatrubaev-7cy.1)

Чтобы за один заход получить шесть расшифровок одной своей записи и сравнить их глазами.
Регистрации делает владелец — агент ключей не видит и не просит. Прогон судит владелец.

Инструмент — `bin/stt-bench`. Шаги: завести четыре аккаунта → положить ключи в переменные
окружения → сухой прогон (ничего не отправляет, показывает, что уйдёт) → боевой прогон.

---

## 1. Регистрации

Данные — с официальных страниц вендоров, сверено 2026-08-30. Если экран не совпал, ищи в
меню слово «API keys» — оно есть у всех четырёх.

### AssemblyAI → `ASSEMBLYAI_API_KEY`

1. https://www.assemblyai.com/dashboard/signup — почта + пароль (или Google).
2. Подтвердить почту, войти в дашборд.
3. Ключ на главной дашборда, блок **«Your API key»** — кнопка copy.
4. **Карта не нужна.** Новым аккаунтам дают **$50 кредитов, без срока годности**.
5. Наш прогон: universal-2 + диаризация = $0.17/ч → 15-минутная запись ≈ **$0.04** за прогон.

### Speechmatics → `SPEECHMATICS_API_KEY`

1. https://portal.speechmatics.com — «Sign up», почта + пароль.
2. Подтвердить почту, войти в Portal.
3. **Settings → API Keys → Create** (задать имя, например `noteapp-bench`).
   Ключ показывается **один раз** — скопировать сразу.
4. **Карта не нужна.** На старте **$100 кредитов**; карту просят, только когда кредиты кончатся.
5. Наш прогон: operating_point `enhanced` = $0.40/ч → 15 минут ≈ **$0.10** за прогон.

### ElevenLabs → `ELEVENLABS_API_KEY`

1. https://elevenlabs.io — «Sign up», почта + пароль (или Google).
2. Войти, в левом меню **Developers → API Keys → Create Key** (в некоторых аккаунтах пункт
   называется просто «API Keys»).
3. При создании ключа выставить разрешения: нужно **Speech to Text**. Лимит по кредитам можно
   не ставить.
4. **Карта не нужна** для free-плана. По Scribe v2 бесплатно **4 ч 30 мин в месяц** — двух
   прогонов 15-минутной записи хватает с большим запасом.
5. Внимание: включённый словарь (`keyterms`) **добавляет +20% к цене** прогона — это политика
   ElevenLabs, стенд учитывает её в столбце «≈$».

### OpenAI → `OPENAI_API_KEY`

1. https://platform.openai.com/signup — аккаунт платформы (аккаунт ChatGPT для API не годится,
   это отдельный биллинг).
2. **Карта нужна.** Бесплатного тарифа у API нет: Settings → Billing → пополнить баланс
   (минимум $5, деньги предоплаченные, не подписка).
3. Ключ: https://platform.openai.com/api-keys → **Create new secret key**. Показывается один раз.
4. Наш прогон: gpt-4o-transcribe-diarize $0.006/мин → 15 минут ≈ **$0.09**.
5. Прогон «со словарём» у этой модели **невозможен**: параметр `prompt` она не поддерживает,
   другого механизма словаря нет. Стенд честно пишет это строкой в таблице — это факт для ADR,
   а не поломка.

### Deepgram — уже есть → `DEEPGRAM_API_KEY`

Тот же ключ, что у приложения. Ничего заводить не надо, только положить в переменную.

## 2. Механизм словаря у каждого свой

Стенд подставляет их сам, таблица — чтобы понимать, что сравнивается, и не упереться в лимит.

| Вендор | Как называется | Лимит | Форма |
|---|---|---|---|
| Deepgram | `keyterm` (query, повторяется) | 500 токенов на запрос | `&keyterm=Сименко&keyterm=noteapp` |
| AssemblyAI | `keyterms_prompt` (JSON) | **200 фраз** для universal-2, ≤6 слов во фразе | массив строк |
| Speechmatics | `additional_vocab` (JSON) | 1000 записей, ≤6 слов | `[{"content": "Сименко"}]`, можно `sounds_like` |
| ElevenLabs | `keyterms` (multipart) | 1000 терминов по 50 символов, **+20% к цене** | JSON-массив строк |
| OpenAI | **нет** | — | `prompt` у diarize-модели не поддерживается |

Самый жёсткий общий лимит — 200 (AssemblyAI). Держи словарь короче: имена, которые вендор
реально путает. Стенд обрезает список сам, но обрезанное сравнение — уже не то сравнение.

## 3. Словарь имён

```bash
cp docs/research/stt-bench-words.example.txt ~/stt-words.txt
$EDITOR ~/stt-words.txt      # по одному термину в строке, строки с # игнорируются
```

Держать **вне репозитория**: это личные имена. В примере лежит «Сименко» и техслова.

---

## 4. Ключи в окружение

Ключи живут только в переменных окружения одной сессии терминала. Стенд их не печатает,
не пишет в файлы и не коммитит; в сухом прогоне вместо ключа печатается имя переменной.

```bash
export DEEPGRAM_API_KEY=...
export ASSEMBLYAI_API_KEY=...
export SPEECHMATICS_API_KEY=...
export ELEVENLABS_API_KEY=...
export OPENAI_API_KEY=...
```

Не класть в `~/.zshrc` и не в файл внутри репозитория. Ключа нет — соответствующий вариант
просто пропускается строкой «нет $X_API_KEY, пропущено», остальные гонятся.

## 5. Проверка стенда до траты кредитов — сухой прогон

```bash
bin/stt-bench ~/zapis.m4a ~/stt-words.txt --dry-run
```

Ни одного сетевого запроса. На экране — все 12 прогонов: какие ключи найдены, какой URL,
какие заголовки (с именем переменной вместо ключа), какое тело и какой словарь уйдёт в каждый.
Сухой прогон работает даже без записи и без ключей — можно посмотреть заранее.

Что смотреть глазами:

- у Deepgram-контроля строка параметров совпадает с приложением
  (`model=nova-3&language=multi&diarize=true&utterances=true&punctuate=true&smart_format=true` —
  см. `app/src/main/kotlin/.../DeepgramClient.kt`);
- в прогонах «со словарём» видны сами термины;
- варианты без ключа честно помечены пропуском.

Проверка собственной логики стенда (разбор ответов, поиск спорных мест, сборка multipart) —
на фикстуре, без сети:

```bash
bin/stt-bench --selftest      # ждём «selftest: ок»
```

## 6. Боевой прогон

```bash
bin/stt-bench ~/zapis.m4a ~/stt-words.txt --out ~/stt-bench-out
```

12 прогонов (6 вариантов × словарь/без). Долгие вендоры (AssemblyAI, Speechmatics) опрашиваются
до готовности. Упавший вариант не роняет остальные — причина попадает строкой в таблицу.
Один вендор зарегистрирован позже остальных — догнать его отдельно:
`bin/stt-bench ... --only speechmatics`.

В каталоге результата:

- `summary.md` — **сюда смотреть**: сверху таблицы по спорным местам («Сименко» и
  «а чё ты кстати эту систему ввёл … давай обсудим») — что именно услышал каждый вариант,
  рядом друг с другом; ниже цена, время и снятые факты;
- `NN-вариант-bez.md` / `-slovar.md` — расшифровки репликами;
- `NN-вариант-*.json` — **сырые ответы вендоров целиком**: форма JSON, пословные таймкоды,
  имена спикеров. Это вход для тикетов 7cy.2 (словарь на телефоне) и 7cy.3 (правка транскрипта).

Свою спорную фразу можно добавить: `--probe "текст как было на самом деле"`.

## 7. Приватность: что учесть до загрузки

Прогон отправляет **реальную личную запись** в четыре новых сервиса. Что они с ней делают
(по их докам, `docs/research/stt-choice.md`):

- **AssemblyAI** — аудио удаляется за 24–48 ч, транскрипты за 30 дней; часть файлов может идти
  в обучение, есть self-serve отказ в Data Controls (включить до прогона, если важно).
- **Speechmatics** — аудио, транскрипты и конфиг хранятся 7 дней, можно удалить раньше.
- **ElevenLabs** — срок хранения в доках STT не оговорён.
- **OpenAI** — данные API по умолчанию не идут в обучение.
- **Deepgram** — транскрипты не хранит вовсе.

Результаты прогона содержат расшифровку личного разговора. Каталог `stt-bench-out/` внесён в
`.gitignore` — не коммитить его и не класть в репо заметок.
