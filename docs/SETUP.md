# Мануал: настройка с нуля

Полный путь от пустого телефона до «нажал кнопку — заметка с саммари лежит в GitHub».
Порядок важен: сначала облачная часть (репо заметок, токены), потом телефон.

## Что понадобится

- Телефон на Android 14+ (собрано и проверено на OnePlus 13, OxygenOS 15).
- Аккаунт GitHub (репо заметок будет приватным).
- Ключ Deepgram — расшифровка речи ([console.deepgram.com](https://console.deepgram.com), у бесплатного тарифа есть стартовый кредит).
- Подписка Claude Max — для саммари в GitHub Action (контракт — OAuth-токен Max-подписки).

## 1. Репо заметок

1. Создай **приватный** репозиторий. Адрес репо зашит в код приложения
   (`Settings.DEFAULT_REPO` = `Roflochinsky/voice-notes`) — экрана настройки для него нет;
   другое имя — поменяй константу и пересобери APK.
2. Ветка по умолчанию должна называться **`main`** — приложение читает готовые заметки
   именно из неё.
3. Папки (`inbox/`, `встречи/`, `идеи/`, …) заранее создавать не нужно — телефон пушит в
   `inbox/`, остальное раскладывает Action.

## 2. Claude-Action в репо заметок

Action срабатывает на каждый пуш в `inbox/`: пишет саммари, определяет тип и участников,
переименовывает файл и переносит его в папку типа. Контракт формата — спека
[`docs/specs/2026-08-24-note-format.md`](specs/2026-08-24-note-format.md).

1. Получи OAuth-токен Claude Code: на компьютере выполни `claude setup-token` и скопируй результат.
2. В репо заметок: Settings → Secrets and variables → Actions → New repository secret,
   имя `CLAUDE_CODE_OAUTH_TOKEN`, значение — токен из шага 1.
3. Положи в репо заметок файл `.github/workflows/process-notes.yml` — эталон:
   [`docs/examples/process-notes.yml`](examples/process-notes.yml) (копия рабочего workflow).
   Ключевое в нём: триггер `on: push` по путям `inbox/**` + релей-джоб, который
   перезапускает workflow как `workflow_dispatch` (сам `claude-code-action` событие push
   не поддерживает — ADR `adr/2026-08-25-action-trigger-relay.md`), `permissions:
   contents: write` и `actions: write`, шаг `anthropics/claude-code-action@v1` с
   промптом-контрактом из спеки.

## 3. Токен GitHub для телефона

Телефон пушит заметки через API, ему нужен свой токен:

1. GitHub → Settings → Developer settings → **Fine-grained tokens** → Generate new token.
2. Repository access: **только репо заметок**.
3. Permissions → Repository permissions → **Contents: Read and write**. Больше ничего.
4. Срок — на свой вкус (истечёт — телефон покажет ошибку пуша, заметки подождут в очереди;
   замени токен в приложении, и очередь уйдёт сама).

## 4. Установка APK

1. На телефоне открой [Releases](https://github.com/Roflochinsky/noteapp/releases) этого
   репо и скачай `.apk` свежего релиза.
2. Разреши установку из браузера, когда телефон спросит, и установи.
3. Обновление — так же поверх: скачал новый APK → установил. Данные и настройки на месте,
   пока релизы собираются на той же машине: сборка подписана её debug-ключом
   (`~/.android/debug.keystore`). Потеряешь/пересоздашь ключ — апдейт не встанет,
   а переустановка удалит локальные записи (аудио живёт только в приложении). Береги ключ.

## 5. Онбординг в приложении

Первый запуск показывает чеклист из пяти шагов — каждый открывает нужный экран сам:

| Шаг | Что происходит |
|---|---|
| **Назначить ассистентом** | Системные настройки цифрового ассистента: выбери MyNoteBook вместо Gemini. Это отдаёт приложению long-press кнопки питания. |
| **Микрофон и уведомления** | Стандартные разрешения записи и нотификаций. |
| **Подключить GitHub** | Вставь токен из шага 3. Репо по умолчанию — `Roflochinsky/voice-notes`. |
| **Ключ Deepgram** | Вставь API-ключ из консоли Deepgram. |
| **Батарея без ограничений** | Исключи приложение из оптимизации батареи — иначе система убьёт длинную запись в фоне. |

Кнопка «Продолжить» откроется, когда все пять шагов зелёные.

## 6. Проверка

1. Заблокируй телефон. Долгое нажатие кнопки питания — появится уведомление с таймером.
2. Скажи пару фраз. Ещё одно долгое нажатие — стоп.
3. Через минуту-две: в репо заметок в `inbox/` появится raw-файл, затем Action перенесёт
   его в папку типа уже с саммари. В приложении заметка пройдёт статусы пайплайна.

## Если что-то не работает

- **Long-press не стартует запись** — роль ассистента слетела (например, после обновления
  системы). Онбординг-шаг «Назначить ассистентом» покажет это; назначь заново.
- **Заметка висит в очереди** — нет сети или умер GitHub-токен. Появится сеть — уйдёт сама;
  на ошибку токена — замени его в приложении и повтори отправку из карточки заметки.
- **Расшифровка падает** — проверь ключ Deepgram и остаток кредита в консоли Deepgram.
- **Саммари не появляется** — смотри вкладку Actions репо заметок: чаще всего истёк
  `CLAUDE_CODE_OAUTH_TOKEN` (перевыпусти через `claude setup-token`) или упал лимит подписки.
- **Аудио** в git не пушится никогда — оно только на телефоне. Удаление приложения удалит
  записи; заметки в GitHub останутся.
