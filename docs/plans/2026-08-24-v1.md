# План: v1 (один эпик)

Спека: docs/SPEC.md (+ docs/specs/2026-08-24-note-format.md). Решение владельца 2026-08-24:
всё строительство v1 — в рамках одного эпика. Журнал попыток, вердикты ревью, ретро — сюда.

## Срезы (LLD)

### С1 — транскрипт: после стопа файл уходит в Deepgram, текст виден в приложении
- Поднять запись до 44100 Гц stereo→mono AAC ~96 кбит (риск №3 спеки).
- После REC_STOP: POST на api.deepgram.com (model=nova-3&language=multi&diarize=true&
  utterances=true&punctuate=true&smart_format=true), ключ — из настроек приложения
  (EncryptedSharedPreferences/DataStore; онбординг введёт руками).
- Ответ парсится в реплики «Спикер N + [мм:сс] + текст» (маппинг из note-format.md),
  сохраняется рядом с аудио (json+md локально).
- Ошибки сети/API → статус «в очереди», ретрай среза С3; вручную — кнопкой.
- Seam для тестов: чистый маппер DeepgramResponse→Transcript (JVM-юнит на живом образце
  docs/research/deepgram-sample-response.json).
- Демонстрация: записал голосом → через секунды транскрипт на экране приложения.

### С2 — заметка в GitHub: raw.md появляется в inbox/ репо заметок
- Сборка raw.md строго по note-format.md (frontmatter recorded/duration/device/status:raw).
- Пуш через GitHub Contents API (PUT /repos/{owner}/{repo}/contents/inbox/<имя>.md),
  токен fine-grained (contents:write на один репо) — из настроек приложения.
- Seam: чистый билдер RawNote(md-строка) — JVM-юнит.
- Демонстрация: записал → файл виден в GitHub в inbox/.

### С3 — офлайн-очередь: нет сети — заметка ждёт и уходит сама
- WorkManager: цепочка «транскрипт → пуш» с Constraint NETWORK_CONNECTED, backoff.
- Статусы заметки: записана → расшифровка → в очереди → в GitHub (для ленты С5).
- Демонстрация: авиарежим → запись → снять авиарежим → заметка сама дошла до GitHub.

### С4 — Action: пуш raw → done-заметка с саммари в папке типа
- Workflow в репо заметок: on push paths inbox/**, anthropics/claude-code-action@v1,
  claude_code_oauth_token из секретов; промпт — из note-format.md.
- Демонстрация: пуш raw → через минуту done-файл в встречи/… с саммари.

### С5 — UI лента (главный экран по компу «Документ»)
- Лента документов с превью и статусом-шёпотом, разделители дат, пустое состояние с
  иллюстрацией, кнопка Записать + подсказка. Roboto. Комп — жёсткое ограничение.
- Демонстрация: скриншот рядом с компом + живой список на телефоне.

### С6 — UI деталка (вкладки по компу)
- Вкладки: Саммари (решение владельца 2026-08-24: КОНТЕНТ показываем в приложении — GET
  done-файла из репо заметок тем же токеном, парсинг frontmatter+секции Саммари; пока Action
  не отработал — состояние «саммари готовится»), Транскрипт (спикеры на полях), Аудио
  (волна+плеер+моменты). Действия: GitHub/Поделиться.
- Демонстрация: открыл заметку → транскрипт и аудио на телефоне.

### С7 — UI запись-шторка + уведомление
- Bottom-sheet поверх ленты: таймер, волна по амплитуде, стоп; уведомление Стоп+Момент.
  Флажки моментов УТВЕРЖДЕНЫ (решение D=да, 2026-08-24): тайм-коды в raw.md отдельной
  секцией «## Моменты», Action использует их в саммари.
- Демонстрация: запись выглядит как в компе, стоп из шторки и уведомления.

### С8 — онбординг-чеклист
- 4 шага по компу: ассистент (deep-link в настройки + проверка isRoleHeld), разрешения,
  GitHub (токен+репо), ключ Deepgram. Плюс чеклист батареи OxygenOS (§5.5) шагом «про запас».
- Демонстрация: чистая установка → по чек-листу до первой заметки в GitHub.

### С9 — выживаемость и добивка (P7)
- Прогон 30–60 мин записи с погашенным экраном (владелец), фиксация в probe-results.md;
  самопроверка при старте (роль, разрешения, батарея) с бейджем в ленте.
- Демонстрация: часовая запись дожила до стопа и дошла до GitHub.

Зависимости: С2←С1; С3←С2; С4←С2; С5←С2; С6←С1; С7,С8 — сразу; С9←С3,С7.
