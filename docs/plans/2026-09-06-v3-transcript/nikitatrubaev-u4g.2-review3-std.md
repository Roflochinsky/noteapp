## 4. Мутации

**Принимаю: шестнадцать плюс управляющая, `--scope full`, все убиты.**

- Шестнадцать `M1…M16` — по строке на каждую, все `убита`; плюс `управляющая: убита` и
  `полный прогон под управляющей: убита`. Строка «полный прогон под управляющей» печатается
  только при `--scope full` (`mutate.py:405-410`) — значит скоуп тот, что заявлен.
- **rc=0** — вывод «ОТКАЗ …» отсутствует, ни одной «выжила», управляющая убита; по
  `mutate.py:414-430` это ровно код 0.
- **Ровно одно падение под полным прогоном** — не на слово: `убита` по `verdict`
  (`mutate.py:259-276`) означает «валидный прогон И `failed == 1` И имя совпало с `expect_fail`».
  К строке полного прогона не приписано `· широкий радиус: упало N` — эта приписка появляется
  только при непобитом полном прогоне. Стражи не пересекаются.

**Новые три — разделяющие, а не ломающие всё подряд.** У каждой падает ровно один тест, и именно
тот, что заявлен в `claim`: `M14` → тест про повторяемый код; `M15` → новый тест про запись без
причины (а не старый про запись с причиной — то есть мутация разделяет два случая, а не гасит
оба); `M16` → `отказ вендора — в причине код и начало тела ответа одной строкой`. Фильтр `tests`
у всех трёх сужен до одного теста, как требовало задание.
