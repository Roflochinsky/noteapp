### 3. Вынесенный шов `transcribeById` — суд моей оси

**Устройством ради теста не считаю. Это шов под потребителя, который в срезе есть, и сделан он
идиомой самого репозитория.** Доводы, по порядку веса:

1. **Форма — ровно образец репо.** `GithubClient.kt:24-34` объявляет швы параметрами с **боевым
   значением по умолчанию** и в KDoc прямо пишет, зачем: «без него цепочка… проверялась бы только
   живой сетью». `transcribeById(context, noteId, stt = ElevenLabsClient()::transcribe)` — тот же
   приём, тот же словарь. Конвенция репо бьёт общее стилевое мнение, а конвенция здесь именно такая.
2. **В бою не прибавилось ни ветки, ни настройки.** Путь один: `doWork` → `transcribeById` с
   умолчанием. Мёртвой гибкости (параметр, ветка или список с одним вызовом, которым никто не
   пользуется иначе) не возникло: параметр используется вторым потребителем — тестом.
3. **Альтернативы проверил сам, а не принял на слово.** `androidx.work:work-testing` в
   `app/build.gradle.kts` действительно нет (в блоке зависимостей только `work-runtime-ktx:2.10.0`),
   а трогать этот файл срезу запрещено заданием. Ручная сборка `WorkerParameters` — это уже
   устройство ради теста в чистом виде.
4. **Неохваченная поверхность уменьшилась, а не выросла.** Было: каталог + ключ + вендор + `noteId`
   вне стражей. Стало: вендор по умолчанию + `noteId` из `Data`.

Цена, которую называю честно: `transcribeNote` теперь имеет двух вызывающих (`transcribeById` и
тесты), а прослойка из четырёх строк добавляет один уровень чтения. Это дешевле, чем дыра, которую
она закрыла.

### 4. Честность объявленного долга — согласен с фактом, но формулировку надо поправить

**С фактом согласен полностью.** `X1` подменяет **ключ** (`Settings.elevenLabsKey` →
`deepgramKey`), а не вендора, и ни одна из восьми мутаций не трогает `ElevenLabsClient()::transcribe`.

**Но одна фраза долга неверна и делает его мягче, чем он есть** — см. находку П1 ниже: «подмена
вендора… и не компилируется молча: типы шва разойдутся». Типы как раз совпадают, компилятор
подмену пропустит. С этой поправкой долг назван полно.
