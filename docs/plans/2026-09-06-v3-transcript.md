## LLD среза 1 — заметка распознаётся ElevenLabs

Seams (спека): `TranscriptMapper.fromElevenLabsJson` (новая), `ElevenLabsClient.transcribe`
(новая, по образцу `DeepgramClient`), `TranscribeWorker` (существующий: выбор клиента по ключу).

- `ElevenLabsClient` — `HttpURLConnection`, multipart собирается руками (повторяющиеся поля
  `keyterms` понадобятся частью 2 — сборщик обязан уметь список уже сейчас, это пять строк);
  таймаут чтения не меньше 3 минут (стенд: 97 с на час аудио). Ошибки: не-2xx → исключение с
  кодом и первыми 200 символами тела; `TranscribeWorker` кладёт текст в статус записи.
- `TranscriptMapper.fromElevenLabsJson` — слова → реплики по правилу спеки (тот же `speaker_id`,
  пауза < 1,5 с), `spacing` пропускается, `audio_event` в тексте как `[смеется]`; спикеры
  нумеруются с 1 в порядке появления (как у Deepgram — `speaker_0` → «Спикер 1»). Старый
  `fromDeepgramJson` остаётся; читатель `transcript.json` выбирает разбор по форме
  (`results.utterances` против `words`).
- `Settings`: ключ `elevenlabs_key` рядом с `deepgram_key`; `MainActivity` — строка
  «Ключ ElevenLabs» вместо «Ключ Deepgram» в настройках и онбординге, старый ключ не стирается.
- Тесты: `TranscriptMapperTest` на фикстуре `elevenlabs-sample-response.json` (обрезанный
  боевой ответ со стенда: две смены спикера, один `audio_event`, одна пауза > 1,5 с);
  `ElevenLabsClientTest` на multipart-теле и на 401; `WorkChainsTest` — без ключа воркер не
  стартует. Мутации (обязательные): порог паузы 1,5 → 0 (реплики не склеиваются) убивает тест
  склейки; пропуск `audio_event` убивает тест смеха; выбор разбора по форме — убивает тест
  старой заметки.
- Смоук: `NoteSmokeTest` с `NOTEAPP_SMOKE_TOKEN` и `ELEVENLABS_API_KEY` в окружении на
  30-секундной фикстуре (снять с телефона короткую запись без личного содержания или
  сгенерировать) — в гейте пропускается, как остальные смоуки.
