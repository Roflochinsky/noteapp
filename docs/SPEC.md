# noteapp — спека v1

Дата: 2026-08-24 · Статус: собрана из закрытой wayfinder-карты `nikitatrubaev-pdj` ·
Пункт назначения карты достигнут. Это сводный документ; детали — в дочерних спеках и research.

## Что это

Личный Android-диктофон для OnePlus 13 в духе Plaud Note. Одна кнопка (долгое нажатие
питания) — старт/стоп записи, даже с заблокированного экрана. Дальше всё само: расшифровка →
Markdown-заметка → пуш в приватный GitHub-репо → GitHub Action пишет саммари и раскладывает.
Успех: от «стоп» до готовой заметки в GitHub — без единого действия. Продуктовая правда —
`PRODUCT.md`, глоссарий — `CONTEXT.md`.

## Пользователь и сценарий

Один пользователь (Никита). Поймать мысль или разговор на ходу — телефон в кармане, часто
заблокирован. Язык — русский с английскими вкраплениями. Приложение — «пульт и журнал», не
читалка: заметки читаются в GitHub/Claude.

## Архитектура (HLD)

```
[Кнопка питания] --long-press--> [Ассистент-роль: VoiceInteractionService]
      --onShow--> [RecordingService (FGS microphone)] --stop--> аудио-файл на телефоне
      --> [Deepgram nova-3 multi, diarize] --transcript--> [сборка raw .md]
      --> [очередь/автопуш] --> [GitHub inbox/] --push--> [GitHub Action: claude-code-action]
      --> [саммари + мета + перенос в папку типа] --> заметка done в репо
```

Слои и контракты:
- **Триггер → запись**: сессия шлёт `ACTION_TOGGLE`, `RecordingService` решает start/stop
  идемпотентно. Механизм триггера — **вариант A (VoiceInteractionService)**, подтверждён на
  железе (эпик nikitatrubaev-qt2). Вариант B (ACTION_ASSIST) — спящий фолбэк в коде.
- **Запись → текст**: облачный STT **Deepgram nova-3, language=multi, diarize+utterances+
  punctuate+smart_format** (docs/research/stt-choice.md). Один HTTPS POST с телефона.
- **Текст → заметка**: формат raw↔done, раскладка репо, промпт Action —
  docs/specs/2026-08-24-note-format.md.
- **Заметка → саммари**: GitHub Action `claude-code-action` по OAuth Max-подписки
  (`CLAUDE_CODE_OAUTH_TOKEN`, без API-ключа), триггер `on push` в `inbox/**`.

## Скоуп v1

- Имя приложения: **MyNoteBook** (решение владельца 2026-08-24); пакет com.roflochinsky.noteapp.
- Флажки «Отметить момент» при записи (решение D); саммари читается в деталке из done-файла GitHub (решение E).

- Запись по кнопке питания (тумблер, с локскрина), foreground-сервис микрофона.
- Онбординг-чеклист: назначить ассистентом, разрешения (микрофон, уведомления), GitHub
  токен+репо, ключ Deepgram — всё выдаётся вручную (adb-обходы заблокированы OxygenOS).
- Пайплайн: STT → сборка raw .md → офлайн-очередь → автопуш в GitHub.
- GitHub Action: саммари + классификация + раскладка.
- Экраны по компу «Документ»: лента, деталка (Саммари/Транскрипт/Аудио), запись-шторка,
  онбординг, уведомление. Каждый — отдельный демонстрируемый срез.

## Не-скоуп v1 (явно)

Play Store, кросс-платформа/iOS, офлайн-расшифровка, саммари на телефоне, диаризация
on-device, аппаратные кнопки кроме питания, автоотправка в Telegram, README-оглавление,
плитка Quick Settings, ручные теги, сводный файл задач.

## Открытые риски → в v1

1. **Диаризация** не подтверждена на двух реальных голосах (смоук-тест: имитация не
   разделилась, 8 кГц). Митигация: поднять sample rate записи (44.1/48 кГц), проверить на
   двух людях; фолбэк AssemblyAI в силе. (pdj.7)
2. **Выживаемость фоновой записи** на OxygenOS (30–60 мин) — не прогнана (P7). Чеклист
   §5.5 assistant-role.md (замок в Recents, откл. оптимизации батареи) + самопроверка старта.
3. **Sample rate записи** зонда — 8 кГц, поднять (влияет на текст и диаризацию).
4. **Ручная выдача** роли и разрешений (не программно) — онбординг обязан вести пошагово.
5. **Хранение аудио и приватность** — под ADR-гейтом при реализации.

## План сборки v1

Строится через `/epic` (docs/harness/epic.md). Каркас `app/` (Gradle + гейты ktfmt/detekt/
Lint) и рабочий зонд-триггер уже есть (эпик nikitatrubaev-qt2) — это фундамент, не выброс.
Срезы v1 режутся из этой спеки скиллом to-tickets: по одному демонстрируемому поведению
(экран/этап пайплайна) на срез, UI-срезы — по компу «Документ» как жёсткому ограничению,
показ каждого на реальном OnePlus 13.
