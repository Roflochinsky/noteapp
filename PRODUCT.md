## Platform

android

## Stack

Kotlin + Jetpack Compose (решено в wayfinder-карте nikitatrubaev-pdj). Только личный APK (sideload), без Play Store. Дизайн-макеты до кода делаются как HTML-артборды.

## Users

Один пользователь — Никита (владелец устройства OnePlus 13, OxygenOS 15). Сценарий: поймать мысль или разговор на ходу — телефон в кармане, часто заблокирован. Язык — русский с английскими вкраплениями.

## Product Purpose

Личный диктофон в духе Plaud Note: одно длинное нажатие кнопки питания — старт записи, ещё одно — стоп. Дальше всё само: расшифровка (Deepgram nova-3, с диаризацией), сборка Markdown-заметки, пуш в приватный GitHub-репо, где GitHub Action с Claude (Max-подписка) дописывает саммари и раскладывает по типам. Успех: от нажатия «стоп» до готовой заметки в GitHub — без единого действия.

## Operating Context

- Запись стартует с заблокированного экрана через системную роль «цифровой ассистент» (long-press power). Экранов приложения при записи можно вообще не видеть — только уведомление с таймером и кнопкой стоп.
- Приложение — «пульт и журнал», не место чтения: заметки читаются в GitHub/Claude. В приложении — статус пайплайна, транскрипт, плеер, повтор при ошибке.
- Офлайн-очередь: нет сети — заметка ждёт и уходит сама.

## Capabilities and Constraints

- Типы заметок: встреча, идея, задача, личное, другое (папки в репо заметок).
- Участники («с кем») извлекаются Claude из транскрипта; диаризация помечает «Спикер 1/2».
- Аудио живёт только на телефоне; в git не пушится.
- Терминология — глоссарий в CONTEXT.md (Запись, Заметка, Кнопка, Пайплайн, Очередь…).
- Настройки: назначение ассистентом, разрешения, GitHub-токен и репо, ключ Deepgram.
- Имя приложения: MyNoteBook (решено 2026-08-24); пакет com.roflochinsky.noteapp, репо noteapp.

## Product Principles

1. Кнопка важнее экрана: любой UI вторичен относительно «нажал — записалось».
2. Нулевое трение после стопа: пайплайн не задаёт вопросов.
3. Приложение — журнал и пульт, чтение живёт в GitHub.
4. Ошибка не теряет запись: аудио на месте, обработку можно повторить.
5. Один пользователь — никакого UI «для всех»: настройки честно технические.
