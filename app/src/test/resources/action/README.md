# Эталонная пара: что оставляет после себя Action

Это контракт между слоями, а не пример. Файлы здесь — вид того, что промпт
`docs/examples/process-notes.yml` пишет в репо заметок, плюс `note-raw-*.md` — тот вход от
телефона, из которого это сделано; по ним проверяется парсер приложения. Схема полей живёт
в одном месте — ADR
`docs/adr/2026-08-26-tasks-as-files.md`; эти файлы её иллюстрируют, а не переопределяют.

**Кто их читает** (долг закрыт 2026-08-29, `bd nikitatrubaev-0rk.8`):

- `ActionFixtureTest` — пара целиком: порядок ключей frontmatter заметки и её поля v2
  (`project`, `tags`), секция «Задачи» состоит только из ссылок, ссылки разрешаются в
  соседние файлы задач, `source` в задачах сходится с именем заметки, обязательные поля
  задачи-минимума (`priority`, `status`) в файле есть, а необязательных нет, транскрипт
  done-заметки побайтово равен транскрипту своей raw-половины;
- `DoneNoteParserTest` — то, что приложение показывает в деталке: мета, саммари блоками
  через пустую строку, заметка без задач.

Инлайн-фикстуры в этих тестах больше нет: своя копия формата молча отстала бы (до 2026-08-29
`DoneNoteParserTest` так и жил в v1 — задача чекбоксом, блоки саммари слитно).

**Правило: промпт меняется только вместе с этой фикстурой.** Правишь промпт в
`docs/examples/process-notes.yml` — тем же коммитом приводишь сюда новый вид файлов и
чинишь упавшие тесты парсера. Иначе четыре копии схемы (ADR, парсер, промпт, рабочая копия
workflow в репо заметок) разъедутся молча и вылезут в рантайме.

**Происхождение.** Обе done-заметки собраны вручную из raw-файлов, лежащих в тестовом репо
`Roflochinsky/voice-notes-test`: `inbox/2026-08-26-0914.md` и `inbox/2026-08-26-2103.md`.
Сами raw-файлы лежат здесь же — `note-raw-with-tasks.md` и `note-raw-no-tasks.md`, сняты из
того репо как есть (git-хеши блобов `2e60374…` и `5e57030…` сходятся с теми, что отдаёт
GitHub на `inbox/`). Секции «## Транскрипт» скопированы в done-заметки **побайтово** — промпт
запрещает Action переписывать транскрипт, поэтому и в фикстуре он обязан совпадать с входом
посимвольно. Это закрыто тестом `ActionFixtureTest`
«транскрипт done-заметки — байт в байт транскрипт raw» (долг `bd nikitatrubaev-0rk.12`):
хвост файла от `## Транскрипт` у done и raw сравнивается как текст, мимо парсера, и отдельно
проверяется пустая строка после заголовка.
Прогона Action на этих входах ещё не было (в тестовом репо нет секрета
`CLAUDE_CODE_OAUTH_TOKEN`); когда он пройдёт, результат сверяется с этими файлами.

Каждое поле должно выводиться из транскрипта — фикстура, где мета взялась из головы автора,
контракт не задаёт. Проверка для `note-done-with-tasks.md`:

| Поле | Откуда в транскрипте |
|---|---|
| `participants: [Дима, Никита, Серёга]` | «Слушай, Дим,» и «Успею, Никит.» → каноничные `Дима`/`Никита` из `people.md`; `Серёга` в реестре отсутствует и остался как услышан — реестр Action не пополняет |
| `project: tgsum` | «Это же tgsum, релиз в пятницу» — слаг есть в `projects.md` |
| `tags: [релиз]` | там же, «релиз в пятницу» |
| `priority: P1` у первой задачи | «Значит, лимит — срочно» |
| `due: 2026-08-27` | «К четвергу успеешь?» — ближайший четверг |
| Подзадачи | «подними лимит и добавь экспоненциальный бэкофф» — ровно два шага |
| Вторая задача без `project`/`due`/`tags` | «мне надо кабель для стенда докупить» — ни проекта, ни срока не прозвучало, поля опущены целиком |

| Файл | Что фиксирует |
|---|---|
| `note-done-with-tasks.md` | Заметка после обработки: порядок ключей frontmatter, блоки саммари через пустую строку, секция «Задачи» — только ссылки `../tasks/…`, чекбоксов-дублей нет. Транскрипт остался как от телефона («Спикер N»). |
| `note-done-no-tasks.md` | Обратная совместимость: задач в разговоре нет → секции «Задачи» нет, всё остальное как в v1. Ни проекта из реестра, ни тегов не прозвучало → поля опущены, не пустые. |
| `2026-08-26-podnyat-limit-retraev.md` | Задача со всеми полями: `source` указывает на **конечный** путь заметки (папка типа, не `inbox/`), подзадачи — плоские чекбоксы. |
| `2026-08-26-kupit-kabel.md` | Задача-минимум: необязательные поля (`project`, `due`, `tags`) и секция «Подзадачи» опущены целиком, файл заканчивается на закрывающем `---`. |
| `note-raw-with-tasks.md` | Вход: `inbox/2026-08-26-0914.md` от телефона (`status: raw`, мета только от диктофона, из секций одна «Транскрипт»). С ним сверяется транскрипт `note-done-with-tasks.md`. |
| `note-raw-no-tasks.md` | Вход: `inbox/2026-08-26-2103.md`, пара к `note-done-no-tasks.md`. |

Имена файлов задач — реальные, как они лягут в `tasks/`: ссылки из
`note-done-with-tasks.md` разрешаются в соседние файлы этой же папки, поэтому пару можно
проверить тестом целиком. Обе задачи — из одной заметки
`встречи/2026-08-26-0914-limity-retraev.md`; ссылки в заметке и `source` в задачах сходятся.
Инвариант, на котором держится относительная ссылка: папки типов — первого уровня,
вложенных папок в репо заметок нет (решение 22 плана).

Чего здесь нет и почему: коллизия имён (`-2`, `-3`) — правило промпта, отдельного файла не
требует; поле `done` — его ставит приложение при закрытии задачи, Action создаёт только
`status: open`.
