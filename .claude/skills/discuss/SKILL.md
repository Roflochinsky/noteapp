# Обсуждение с протоколом

Интервью ведёт `mattpocock-skills:grilling` (раунды, весь фронтир в ширину). Этот скилл добавляет
то, чего у него нет: **протокол** в файле, который пишется по ходу, наш ADR-гейт и наши термины.
Решения живут в протоколе, а не в памяти сессии. Перенесено из workwatch (форма 2, раздел A);
wayfinder-карта (`bd show <карта>` → Decisions so far) — полноправный вход: решённое там не
переспрашивать, а вписать в протокол как решения без вопроса.

## Шаги

### 1. Заведи протокол до первого вопроса

`docs/discussions/<ГГГГ-ММ-ДД>-<слаг>.md`: шапка `Дата:`, `Цель:` (одной строкой — куда идём),
`Термины:` (пусто), `ADR:` (пусто); разделы `## Цель`, `## Что уже есть`, `## Пока не уточнено`,
`## Вне скоупа`. Путь напечатай владельцу.
**Готово:** файл существует, `Цель` и `Дата` заполнены.

### 2. Собери факты сам, не спрашивая

Read-only исследователи (`na-researcher`, по одному на затронутый слой: приложение / GitHub
Action / формат репо заметок / STT) — что код уже умеет и чего не умеет, со ссылкой на файл.
Findings — в `## Что уже есть`. Вопрос, ответ на который есть в коде, владельцу не задаётся.
**Готово:** по каждому затронутому слою в протоколе есть строка «умеет / не умеет» с путём.

### 3. Гони `grilling` раундами и записывай каждый раунд

После КАЖДОГО раунда — блок `## Раунд N (<ЧЧ:ММ>)` с `### Q<n>.` и `**Ответ:**`. Развилки,
которые владелец уже закрыл (в разговоре или в wayfinder-карте), входят в протокол как
решения без вопроса; интервью идёт раундами до пустого фронтира. Простые слова: владелец
просил объяснять смысл раньше техники (`/wait-what`).
Решения оформляй сразу: `## Решение N. <заголовок>` со строками `Автор: владелец|ведущий`,
`Увидишь: <действие> → <результат>`; у решения с автором `ведущий` — строка
`Подтверждено владельцем: да` после его слов.
**Готово:** последний раунд закрыт словами владельца «вопросов нет»; у каждого `### Q`
непустой `**Ответ:**`.

### 4. Снимай термины в момент, а не в конце

Двусмысленный термин — `mattpocock-skills:domain-modeling` тем же ходом и правка `CONTEXT.md`
(глоссарий); термин — в шапку `Термины:`.
**Готово:** каждый термин из шапки находится `grep -F` в `CONTEXT.md`.

### 5. Прогони ADR-гейт

Список тем — `CLAUDE.md` → _ADR-гейт_ (формат заметки, контракт Action, STT и его параметры,
триггер записи, аудио и приватность). Сработал — скилл `adr` тем же ходом.
**Готово:** в шапке `ADR: <путь> | не затронут`.

### 6. Закрой фронтир

Видно, но не спрошено → `## Пока не уточнено`; сознательно вне цели → `## Вне скоупа` с
причиной. Пустой раздел пишется словами «пусто, потому что …».
**Готово:** `scripts/discuss-check.py <протокол>` выходит с кодом 0; владелец подтвердил
итоговый список решений словами.

### 7. Вторая пара глаз

Отдельный агент (`na-reviewer`, не автор интервью; рубрика идёт промптом) читает протокол по пяти вопросам: фронтир пуст (назвать незаданный
вопрос или «не нашёл»); решение — решение, а не пересказ вопроса; двусмысленность (два
прочтения названы); непротиворечивость с ADR в `docs/adr/`; молчаливое допущение за
владельца. Вердикт `APPROVE` / `CHANGES REQUESTED` / `ВЛАДЕЛЬЦУ` — в конец протокола;
`ВЛАДЕЛЬЦУ` обязателен, если агент сам принял решение из списка ADR-гейта.
**Готово:** вердикт записан; `ВЛАДЕЛЬЦУ` и блокеры сняты до вызова `to-spec`.

Дальше — `to-spec` (спека в двух частях).
