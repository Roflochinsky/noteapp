# Ревью замысла

Самая дешёвая проверка эпика (замер workwatch `ww-usgj`: 6 % агент-времени, 14 блокеров, ноль
кругов правки кода). Оси — параллельные агенты `na-reviewer` (канал `Agent`, `fable`); HLD и
LLD с усилием high, бизнес и UX — medium. Рубрики и права — `docs/harness/epic.md` → _Ревью
замысла_. Перенесено из workwatch (форма 2, раздел D).

## Шаги

### 1. Выбери оси по типу работы

Приложение, данные, пайплайн (запись → STT → `.md` → пуш → Action) → HLD + LLD. Продуктовая
логика → бизнес. UI, экран → UX. Смешанная задача — все подходящие. Один слой и ADR-гейт не
сработал — ревью не нужно, это не эпик.
**Готово:** список осей напечатан в чат одной строкой.

### 2. Диспатчи оси с их входами

Вход каждой оси: спека (обе части), план, протокол обсуждения, `PRODUCT.md`, `CONTEXT.md`;
UX — плюс `DESIGN.md`, утверждённый комп и его скриншот из `docs/design/`. В промпт — рубрика
оси из `docs/harness/epic.md` дословно, права по автору, форма вердикта и путь отчёта.
**Порядок:** бизнес и UX параллельно, пишут в `docs/plans/<слаг>/review-<ось>.md`; HLD правит
план сам, LLD — после HLD (план — общий замок). Правки в дерево ведущего из изолированного
дерева — через шелл (`cat > … <<'EOF'`). Отчёт пишется нарастающим итогом.
**Готово:** каждой оси отдан промпт с входами и путём отчёта.

### 3. Прими вердикты

Три значения: `APPROVE` (замысел лучше его отсутствия), `CHANGES REQUESTED` (только с
конкретным неверным поведением и примером «вход → ожидаемый выход»), `ВЛАДЕЛЬЦУ` (критерий
приёмки, не-скоуп, видимая владельцу семантика, тема ADR-гейта, смысл решения). Остальное —
`Nit:` в план. После каждой оси: `git diff --name-only` без `docs/specs/` и `docs/adr/`.
**Готово:** по каждой оси письменный вердикт с разделами «Блокеры / Nit / Правил сам /
Вынес владельцу»; молчание об оси = ось не пройдена.

### 4. Сведи

Сведение — работа ведущего, оси между собой не договариваются. Блокеры — правка спеки или
плана ведущим до первого среза; `Nit` из бизнес- и UX-файлов — в план; `ВЛАДЕЛЬЦУ` — в пачку на
апрув. Отчитались — агентов гасить (`TaskStop`) в том же ответе.
**Готово:** в плане раздел «Ревью замысла» с вердиктами всех осей и списком вынесенного владельцу.
