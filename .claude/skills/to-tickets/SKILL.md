# Срезы из спеки

Срез — **узкий, но полный путь через все слои, который можно показать сам по себе**.

## Шаги

### 1. Возьми спеку

Путь даёт пользователь или `bd show <эпик>`. Прочитай целиком: решения, не-скоуп, критерии приёмки.
**Готово:** выписаны критерии приёмки, которые срезы обязаны закрыть — все до одного.

### 2. Отдели то, что режется, от того, что ведётся expand–contract

Широкий рефактор и смена формата (переименовать поля frontmatter, перекроить папки репо
заметок) в срез не влезают: одна правка ломает все места сразу, и зелёным не будет ни один
срез. Веди их expand–contract: добавить новую форму → перевести читателей партиями →
удалить старую форму отдельной последней задачей.
**Готово:** каждый кусок работы отнесён к «вертикальный срез» или «expand–contract».

### 3. Нарежь срезы

На каждый ответь вопросом **«что я смогу показать, когда это готово?»**. Ответ обязан быть
ПОВЕДЕНИЕМ — «зажал кнопку питания на локскрине, файл записи появился в папке приложения», —
а не слоем («сервис записи», «клиент Deepgram», «workflow»). Получился слой — срез
горизонтальный, режь заново.

Каждый срез:
- проходит все свои слои — от триггера до наблюдаемого результата;
- демонстрируем или проверяем в одиночку (на телефоне, в тестовом репо, в логе workflow);
- влезает в одно свежее контекстное окно исполнителя;
- префактор («сделай изменение лёгким, потом сделай лёгкое») идёт первым срезом.

**Готово:** у каждого среза записана одна фраза-поведение, и вместе они закрывают критерии
приёмки из шага 1.

### 4. Заведи срезы в beads

По срезу — issue, в порядке зависимостей (блокирующие первыми):

```bash
bd create --parent=<эпик> --type=task --priority=<0-4> \
  --title="<поведение коротко>" \
  --description="Продукт: <ценность одним предложением>

<что заработает, границы среза, чем проверяется, пути спеки и плана>"
```

Пути файлов и куски кода держи вне описания — исполнитель читает спеку и план по ссылке.
**Готово:** `bd ready --parent <эпик>` печатает срезы без блокировок.

### 5. Проставь зависимости

`bd dep add <срез> <блокирующий-срез>` — по команде на ребро. Ребро ставь только там, где
второй срез действительно нельзя начать раньше.
**Готово:** `bd blocked` показывает ровно те срезы, у которых есть ребро.

### 6. Сдай разбиение человеку

Напечатай нумерованный список: заголовок среза, «увидишь: <поведение>», «ждёт: <срезы>» или
«берётся сразу». Он уходит владельцу в пачку на апрув (остановка на апрув, режим 1 `epic`).
Родительский эпик оставь как есть — не правь и не закрывай.
**Готово:** список напечатан, у каждого среза есть строка «увидишь».
