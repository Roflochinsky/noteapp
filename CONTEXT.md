# noteapp — глоссарий

- **Запись (Recording)** — аудиофайл, снятый с микрофона между «старт» и «стоп». Живёт только на телефоне, в git не попадает.
- **Заметка (Note)** — итоговый `.md`-файл в GitHub-репо заметок: frontmatter + саммари + транскрипт. Одна запись → одна заметка.
- **Кнопка (The Button)** — long-press кнопки питания. Тумблер: первое нажатие — старт записи, следующее — стоп. Единственный обязательный способ управления записью.
- **Ассистент-роль (Assistant role)** — системная роль Android «цифровой ассистент», через которую приложение получает long-press кнопки питания.
- **Транскрипт (Transcript)** — текст записи из STT, реплики помечены спикерами («Спикер 1/2»).
- **Диаризация (Diarization)** — разделение транскрипта по голосам говорящих. Делается STT-сервисом, не Claude.
- **Саммари (Summary)** — выжимка заметки, пишется Claude в GitHub Action, стоит сверху файла заметки.
- **Тип (Type)** — категория заметки из фиксированного списка: `встреча`, `идея`, `задача`, `личное`, `другое`. Определяет папку в репо заметок.
- **Участники (Participants)** — «с кем» разговор; имена, которые Claude извлёк из транскрипта. Тег заметки, не разметка реплик.
- **Репо заметок (Notes repo)** — приватный GitHub-репозиторий, куда телефон пушит заметки и где работает Action.
- **Очередь (Queue)** — заметки, ожидающие отправки в репо (нет сети / ошибка); уходят автоматически при появлении связи.
- **Пайплайн (Pipeline)** — авто-цепочка после стопа: STT → сборка `.md` → пуш → Action (саммари + классификация).
