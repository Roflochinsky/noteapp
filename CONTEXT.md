# noteapp — глоссарий

- **Запись (Recording)** — аудиофайл, снятый с микрофона между «старт» и «стоп». Живёт только на телефоне, в git не попадает.
- **Заметка (Note)** — итоговый `.md`-файл в GitHub-репо заметок: frontmatter + саммари + транскрипт. Одна запись → одна заметка.
- **Кнопка (The Button)** — long-press кнопки питания. Тумблер: первое нажатие — старт записи, следующее — стоп. Единственный обязательный способ управления записью.
- **Ассистент-роль (Assistant role)** — системная роль Android «цифровой ассистент», через которую приложение получает long-press кнопки питания.
- **Транскрипт (Transcript)** — текст записи из STT, реплики помечены спикерами («Спикер 1/2»).
- **Диаризация (Diarization)** — разделение транскрипта по голосам говорящих. Делается STT-сервисом, не Claude.
- **Саммари (Summary)** — выжимка заметки, пишется Claude в GitHub Action, стоит сверху файла заметки.
- **Тип (Type)** — категория заметки из фиксированного списка: `встреча`, `идея`, `задача`, `личное`, `другое`. Определяет папку в репо заметок. Заметка типа `задача` — документ *про* задачу; сама единица трекера — Задача (см. ниже).
- **Участники (Participants)** — «с кем» разговор; Персоны из реестра. Claude предлагает имена из транскрипта, владелец выбирает/правит в приложении. Тег заметки, не разметка реплик.
- **Задача (Task)** — единица трекера: отдельный `.md`-файл в репо заметок со своими Проектом, Приоритетом, Статусом и Подзадачами; ссылается на заметку-источник. Рождается из заметки (извлекает Action) или создаётся руками в приложении. Не путать с типом заметки `задача`.
- **Подзадача (Subtask)** — чекбокс-строка внутри файла Задачи. Один уровень; своих полей (приоритет, проект) не имеет.
- **Проект (Project)** — метка, к которой относятся задачи и заметки (например, рабочий проект); список проектов — Реестр в репо заметок.
- **Персона (Person)** — человек из Реестра; из персон выбираются Участники заметки, по персоне фильтруется лента.
- **Реестр (Registry)** — файл-справочник в репо заметок: реестр проектов, реестр персон.
- **Приоритет (Priority)** — важность задачи: P1 (высокий) / P2 (обычный) / P3 (низкий).
- **Статус задачи (Task status)** — `open` / `in_progress` / `done`.
- **Миграция (Migration)** — разовый прогон по уже накопленным заметкам: чекбоксы секции «Задачи» превращаются в файлы Задач и ссылки на них. Уходит одним коммитом `migration: tasks v2`, снимается одним `git revert`; повторный прогон ничего не делает — признак «уже мигрировано» и есть состояние самой заметки.
- **Синк (Sync)** — двусторонний обмен приложение ↔ репо заметок через GitHub API. Git — единственный источник правды; приложение держит локальный кэш, git-клона на телефоне нет.
- **Репо заметок (Notes repo)** — приватный GitHub-репозиторий, куда телефон пушит заметки и где работает Action.
- **Очередь (Queue)** — заметки, ожидающие отправки в репо (нет сети / ошибка); уходят автоматически при появлении связи.
- **Пайплайн (Pipeline)** — авто-цепочка после стопа: STT → сборка `.md` → пуш → Action (саммари + классификация).
