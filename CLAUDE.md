# noteapp — правила для агентов

Личный Android-диктофон (OnePlus 13): long-press питания → запись → Deepgram → `.md` →
приватный GitHub-репо → Claude-Action пишет саммари. Продуктовая правда — `PRODUCT.md`,
глоссарий — `CONTEXT.md`, решения — wayfinder-карты (`bd show nikitatrubaev-7cy`, активная v3)
и `docs/adr/`. Потолок этого файла — 250 строк: дело в бюджете инструкций, описательное —
в `docs/harness/` и `docs/agents/`.

## Обязательная верификация

Перед словом «готово» прогнать блоки затронутых слоёв и показать реальный вывод.

| Слой | Команды |
|---|---|
| Приложение (Kotlin) | `bin/gate` (быстрый: `ktfmtCheck detekt testDebugUnitTest`), `bin/gate --full` (+ `lint assembleDebug`, перед сдачей среза) |
| GitHub Actions | `~/go/bin/actionlint docs/examples/process-notes.yml` (эталон для репо заметок; своих workflow у репо нет) |
| Скрипты харнеса | `ruff check scripts && ruff format --check scripts && pytest scripts/tests` |
| Стенд STT | `bin/stt-bench --selftest` (сеть и ключи не нужны) |
| Хуки харнеса | `python3 .claude/hooks/tests/test_destructive_fs_guard.py` (и остальные `test_*.py` там же) |
| Всё разом (гигиена) | `pre-commit run --all-files` |

**Гейт зовётся через `bin/gate`, а не `./gradlew` напрямую.** Обёртка снимает `JAVA_HOME`
(`java` в PATH нет, JDK в `~/.local/java/jdk17`) и `local.properties` (не в git, в свежем
worktree его нет — голый Gradle падает на «SDK location not found»; руками —
`cp ~/code/noteapp/local.properties .`), ставит прогоны в очередь через `flock` и — главное —
ходит `--offline`.
`bin/gate <задачи>` — свои задачи Gradle; `bin/gate --online` — когда сменили версию зависимости.

**Почему `--offline` (замер 2026-08-29):** конфигурация сборки шла **280 секунд**, из них 279 —
ожидание таймаутов сети (тот же обрыв до внешних хостов из WSL, что с GitHub). С `--offline`
конфигурация — 1 секунда, полный гейт с APK — 19 секунд. Зависимости лежат в `~/.gradle/caches`.

**Память:** машина 16 ядер / 11 ГБ, один прогон — Gradle-демон (2 ГБ) плюс Kotlin-демон
(1,5 ГБ); двое разом уводят в своп, поэтому `bin/gate` держит очередь на один прогон, ждущий
прогон убивать не надо. Агент, который НЕ собирает, стоит ~0,5 ГБ. Демоны после снятых агентов
живут и держат по гигабайту: `./gradlew --status`, прибить `IDLE`. **`--rerun-tasks` в заданиях
не писать** (`bin/gate` его не пропустит): полная перекомпиляция, по 5 минут на задачу. Кэш
сборки общий на все worktree (`org.gradle.caching=true`) — и он же ловушка для мутаций и
смоуков, `docs/harness/epic.md` → _Грабли Gradle_.

**Инструменты** — ktfmt (формат), detekt (статанализ), Android Lint, actionlint (workflows),
ruff + pytest (скрипты харнеса). Версии пинить в Gradle и pre-commit синхронно — разъехавшиеся
версии заставляют хук и CI форматировать по-разному (прецедент workwatch).

**Тесты экранов** — Robolectric + `compose ui-test`, в общем `testDebugUnitTest` (`androidTest`
не берём: нужен эмулятор). Кладутся в `app/src/test/kotlin/.../ui/`, образцы —
`TasksScreenTest.kt` и `TaskDetailScreenTest.kt`. Классу **обязателен
`@GraphicsMode(GraphicsMode.Mode.NATIVE)`**: без него текст меряется как 1px на символ, и любая
проверка геометрии либо врёт, либо проходит сама собой. Проверять поведение, а не реализацию:
семантику (клик, роль, описание) и размер узла, а не модификатор.

## Конвейер тяжёлой задачи

Точка входа — скилл **`epic`**: петля «набор срезов → исполнитель → верификация → ревью →
слияние», состояние в `bd` и файле плана; подготовку (`discuss` → `to-spec` → `review-intent`
→ `to-tickets`) ведёт сам. Пилот на воркерах Orca — `epic-orca`, по команде владельца.
Правила, которых нет в чужих скиллах, — `docs/harness/epic.md`: оси и форма вердикта, классы
находок и уровни повторного ревью, замки параллельности, рубрики ревью замысла, ретро.

Глубина работы: ADR затронут → спека, и ничего больше; 2+ слоя или 3+ среза → план. Названное
владельцем решение и есть подпись: записал в ADR — работай. Внутри открытого эпика разрешения
не спрашивают: зелёный гейт → коммит в локальный `main` → следующий срез. **Задача в `bd` —
только срез спеки** (одно видимое поведение); находки ревью живут в вердикте.

## Сабагенты

- Определения — `.claude/agents/na-*.md`: исполнитель `na-executor` (`opus`/medium; класс
  «тихая и дорогая ошибка» — high), ревьюер и ревью замысла `na-reviewer` (`fable`),
  исследователь `na-researcher` (`opus`, только чтение; у `Explore` нет `Write`).
- Один bd-срез = один исполнитель со свежим контекстом и своим деревом
  (`isolation: worktree`, база — локальный `main`): передавай пути к спеке, плану и задаче, а
  не пересказ разговора. Мандат `tdd` и четыре правила границ правки — в определении агента;
  воркеру Orca они идут первыми строками файла промпта.
- **Автор не одобряет свою работу.** Ревью состоялось только при письменном вердикте:
  `APPROVE`, `CHANGES REQUESTED` (только за конкретное неверное поведение с примером
  вход → выход) или `ВЛАДЕЛЬЦУ`. Молчание об оси = ось не пройдена.
- **Сдача — журнал среза `docs/plans/<слаг>/<id>.md`**, ведущий сшивает его в план; строка
  `гейты: <sha> …` с полным выводом файлом в скратчпаде (результат гейта существует только
  вместе с хешем); изменённые файлы против «Трогает:»; таблица `scripts/mutate.py table`;
  риски; путь отката. Приписок самопроверки в промпте нет — доказательство даёт вывод,
  независимость — отдельный ревьюер.
- Сабагент сабагентов не запускает (`CLAUDE_CODE_MAX_SUBAGENT_SPAWN_DEPTH=1`). Отчёт пришёл —
  агент гасится (`TaskStop`) в том же ответе; чужих — вместе с родителем.
- Промпт требует пачек в шелле: независимые команды — одним вызовом, без `cd`; после любого
  `bd` рабочий каталог сбрасывается в корень — в дереве агента `git -C <дерево>`.

## ADR-гейт

Решения, которые нельзя менять без ADR в `docs/adr/` (скилл `adr`, проверка
`scripts/adr-check.py`) и подписи владельца:

- формат заметки `.md` (frontmatter, имена файлов, раскладка папок репо заметок);
- контракт GitHub Action (промпт, триггер, что и куда пишет);
- выбор STT и его ключевые параметры (сейчас: Deepgram nova-3, диаризация);
- механизм триггера записи (ассистент-роль / ACTION_ASSIST);
- всё, что касается хранения аудио и приватности.

**Принятый ADR неизменяем:** изменение по существу — новый ADR, у старого меняется только
шапка (`Status: Superseded by ADR <имя нового>`).

## Окружения и безопасность

- **Телефон владельца — не стенд.** Установка APK, смена роли ассистента, системные
  настройки — только по явному указанию владельца.
- Реальный GitHub-репо заметок и ключи (Deepgram, GitHub token, CLAUDE_CODE_OAUTH_TOKEN) —
  только по явному указанию; для тестов — отдельный тестовый репо `Roflochinsky/voice-notes-test`.
- Деструктивные операции блокирует хук `destructive-fs-guard`; обход `WW_DESTRUCTIVE_OK=1` —
  только после явного одобрения владельцем точной команды. `orca worktree rm` идёт мимо
  стражей — удалять только свои дочерние деревья и только после `worker-release`.
- Пуш в `origin/main` — при закрытии сессии или эпика (домашний `CLAUDE.md` → _Session
  Completion_), не после каждого среза; `git pull --rebase=merges`, чтобы слияния срезов
  не переписались в цепочку. Force-push и ребейз опубликованных коммитов — только с явного
  разрешения. Сообщения коммитов по-русски, со ссылкой на bd-id.

## Карта скиллов

Хук `skill-router` подсказывает автоматически и не блокирует; полная карта:

| Ситуация | Скилл |
|---|---|
| Тяжёлая задача, спека, срезы, петля исполнения | `epic` (наш, `docs/harness/epic.md`) |
| Пилот формы 2 на воркерах Orca, по команде владельца | `epic-orca` |
| Обсуждение перед тяжёлой работой, протокол решений, новая развилка | `discuss` (внутри зовёт `grilling`) |
| Сработал ADR-гейт | `adr` |
| Спека из принятых решений (две части, `spec-check`) | `to-spec` |
| Срезы из спеки в beads («Трогает:», `ready-slices`) | `to-tickets` |
| Ревью замысла до кода | `review-intent` |
| Работа по карте решений | `mattpocock-skills:wayfinder` (v3 «транскрипту можно верить» — nikitatrubaev-7cy, активна) |
| Ревью кода | `mattpocock-skills:code-review` (оси инлайном, `na-reviewer`) |
| Баг, не работает, медленно | `mattpocock-skills:diagnosing-bugs` |
| Любая правка UI | `impeccable:impeccable` — `DESIGN.md` + компы в `docs/design/` (v2 `2026-08-26-comp-v2.html`, v3 `2026-08-30-comp-v3.html`) — жёсткое ограничение |
| Внешние факты (Deepgram, GitHub API, Android) | `mattpocock-skills:research` через `na-researcher` |
| Доки при коммите | `update-docs` |
| Тебя поправили или ошибка повторилась | `codifying-learnings` |
| Непонятно объяснил | `/wait-what` (зовёт владелец) |

## Beads

Трекер — `bd` (workspace домашний), конвенции — `docs/agents/issue-tracker.md`. Задачи проекта —
с описанием «Продукт: …» первой строкой и «Трогает:» последней. Wayfinder-карты — эпики с
меткой `wayfinder:map`; строительные эпики — свои id (v1 `nikitatrubaev-4wi`, v2
`nikitatrubaev-0rk`). TodoWrite и markdown-TODO не использовать; `bd remember` — для знаний
между сессиями.
